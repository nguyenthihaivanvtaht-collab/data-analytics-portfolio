# Transaction Data Analysis

A capstone project from the Summer Data Boot Camp analyzing customer account and transaction data with Python and Power BI.

## Project Overview

This project explores transaction behavior, account characteristics, and activity trends to identify patterns that may help inform customer and business analysis.

## Analysis

- Cleaned and transformed transaction and customer account data.
- Analyzed transaction frequency in relation to account balance.
- Examined transaction behavior by credit score.
- Reviewed transaction trends over time and across branches.
- Explored factors associated with customers maintaining long-term accounts.
- Built an interactive Power BI dashboard to present the analysis.
