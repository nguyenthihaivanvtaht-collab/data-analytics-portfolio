# Sales Analysis and Customer Segmentation

A Business Data Mining course project exploring sales performance, delivery patterns, customer behavior, and product associations using Excel and Python.

## Project Overview

The project analyzes 9,994 transaction records containing order, customer, product, sales, profit, discount, and shipping information. It combines Excel-based summaries with Python analysis to examine business performance and identify customer and product patterns.

## Objectives

- Analyze sales trends by time, product category, customer segment, and region.
- Review order volume and delivery-time patterns.
- Identify high-revenue customers and popular products.
- Explore customer groups using clustering.
- Discover product combinations using association rule mining.

## Tools and Methods

- **Excel:** PivotTables and summary analysis
- **Python:** Jupyter Notebook, pandas, Matplotlib, Seaborn, and scikit-learn
- **Methods:** Data cleaning, exploratory data analysis, K-Means clustering, and association rule mining

## Project Workflow

1. Clean and prepare the transaction data.
2. Summarize sales, order quantities, and delivery metrics.
3. Compare performance across product categories, customer segments, regions, and time periods.
4. Apply clustering to customer sales and order activity.
5. Explore product combinations through association rules.
6. Present findings in charts and Excel analysis files.
